# 七分钟演示脚本

本演示只使用你有权处理的论文。公开录屏或截图前，请检查画面中没有 API Key、私密论文标题、聊天记录或本地文件路径。

## 1. 论文库与导入（45 秒）

打开“论文库与导入状态”，上传一篇可公开演示的 PDF。展示导入状态从校验、解析、分块、Embedding、写入索引到 `ready`，以及论文标题、PDF 页数、chunk 数和 active version。

可选上传其 Supplementary document，并在关联主论文后说明二者共享论文家族工作区。启动一次导入或全文摘要，切换页面再返回，展示后台任务仍保留进度和结果。

## 2. 带出处问答（90 秒）

在“智能对话”选中已导入论文，提问：

> 这篇论文试图解决什么问题？核心方法是什么？请给出证据。

展开 Citation，展示论文名、真实 PDF 页码、稳定 chunk ID 和原文。强调模型只返回 `[C#]`，真实定位由程序依据候选证据回填与校验。

## 3. 证据不足与拒答（45 秒）

提问一个论文未覆盖的问题，例如：

> 论文是否证明该方法可以治疗某种疾病？

展示系统的证据不足提示及其依据：系统不会把模型通用知识误当作论文证据。

## 4. 多 Agent 深度分析（90 秒）

切换到“多 Agent 深度分析”，提问：

> 详细分析这篇论文的整体架构、核心模块、训练策略和实验设计。

展开执行过程，展示协调 Agent 的任务拆解、并行 specialist 完成状态和统一 PDF 引用。说明深度模式最多三个 worker，单节点失败时会降级为带限制说明的结果，避免无界 Tool 循环。

## 5. 多论文比较（90 秒）

在“多论文比较”中选择两篇已导入论文。展示研究问题、方法、数据集、指标、结果、效率和局限等维度；特别指出任务、数据集或指标不同的条目会标记为不可直接比较，而非强行给出优劣结论。

比较完成后导出 Markdown/JSON。返回智能对话，打开任一 Citation 的“查看 PDF 第 N 页”，说明导出中保留引用快照，不依赖当前 Chroma chunk 仍然存在。

## 6. 工程可信度（30 秒）

打开“检索调试”查看逐论文结果与 retrieval trace；打开“RAG 评测”说明可以使用私有标注集衡量 Hit@k、论文范围准确率、引用有效率、拒答准确率和延迟。最后说明 Agent 只负责选择高层 Tool，底层导入事务和引用校验由 Service 层控制。
