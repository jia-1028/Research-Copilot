# 已知限制

1. 当前是单机个人论文库，Streamlit 没有用户认证和多租户隔离。
2. 默认 PyMuPDF 文本解析对扫描 PDF、复杂双栏、公式和表格的结构恢复较弱；用户显式启用 MinerU 时，网络、额度或服务异常仍会自动回到本地路径。
3. PyMuPDF 的 PDF page 是文件物理页，不一定等于论文印刷页码；界面明确显示“PDF 第 N 页”。
4. 整篇摘要的全文 Map-Reduce 仍会产生多次模型调用；多论文比较已改为九维定向证据画像并加入版本缓存。新论文首次画像仍可能需要约一分钟，缓存后的完整比较为毫秒级。
5. 当前没有 cross-encoder reranker；第一版以 embedding 检索、逐论文配额和引用校验为主。
6. 已有 40 条人工标注真实问题，但集中于当前 4 个文档，仍是工程回归集而非可发表的学术基准。
7. arXiv 网络限制、下载失败和论文撤回由外部服务决定。429/503 时系统会停止本轮重复搜索并进入短时冷却，不能绕过远端限流。
8. 第一阶段不包含实验管理、代码仓库分析、MCP、多用户权限或生产部署。
9. 会话数据库当前未加密；快速/深度任务若在模型调用中强制终止，只能从持久化问题重试，不能中点续跑。
10. 旧版未持久化的快速/深度回答正文无法恢复，系统只显示可验证的旧问题与 retrieval trace。
11. `deepseek-v4-flash-vision-exp` 已通过文本、Tool Calling 和图片识别 smoke test，但属于账号可见的实验模型，当前不支持 `response_format`；结构化子任务由 `qwen-plus` 承担。论文页面可以自动进入多模态 RAG，但 Streamlit 对话框目前尚未提供用户手动添加图片附件的入口。
12. 多模态 RAG 当前以相关检索页的完整页面渲染为证据，不做独立 Figure bbox 检测；复杂页面可能包含多个图表。页面图像会增加本地磁盘占用和视觉 token 费用，默认最多发送三页。
13. 后台任务可持久化状态和结果，但 Python 进程不能从一次正在执行的模型/API 调用中点续跑；重启后会从任务入口重新执行。运行中取消同样需要等待当前外部调用返回。
14. PDF 内嵌查看依赖浏览器对 PDF 的支持；若浏览器策略阻止渲染，仍可下载原 PDF，并通过引用旁的页面图像查看证据页。

## Chroma 故障恢复

如果出现 `Error loading hnsw index` 或 `backfill request to compactor`，说明持久化 HNSW 文件与 Chroma 元数据不一致。停止 Streamlit 后运行 `research-copilot repair-chroma`。命令只在 staging 完整重建并通过数量、论文过滤和查询校验后切换生产目录；损坏目录会保留在 `data/backups/`，不要使用仍会访问旧 collection 的单篇“重建当前版本索引”。

## 后续优先级

1. 将评测集扩展到更多领域和 100+ 问题，并加入答案正确性的人工双人复核。
2. 增加 BM25 + dense hybrid retrieval 和可选 reranker，重点修复当前 4 条检索 miss。
3. 增加独立 Figure bbox 检测、caption 对齐以及表格/公式的结构化恢复。
4. 为后台任务增加真正的分布式 worker、租约和可中断网络请求。
5. 数据量或并发足够大时实现 Milvus 适配器并做同基准对比。
