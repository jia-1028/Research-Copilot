# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected credential leak or security vulnerability. If GitHub private vulnerability reporting is enabled for this repository, use it; otherwise contact the repository owner through a private channel.

Never include API keys, access tokens, private PDFs, user conversations, database files or screenshots containing sensitive data in a report. If a credential may have been exposed, revoke it at the provider first, then report the incident.
